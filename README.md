# Site Redirector Pro 🛑

网站重定向助手 - 拦截分心网站，冷静倒计时后重定向到指定网站，帮助你保持专注。

## 功能特点

- **冷静期机制**：30秒倒计时，给你时间思考是否真的要摸鱼
- **红蓝药丸选择**：冷静期结束后，选择「回去干活」或「继续摸鱼」
- **临时绕过**：选择摸鱼后 5 分钟内不再拦截，并记录放行原因
- **防刷新绕过**：刷新页面不会重置冷静期，倒计时会延续当前会话
- **防子域名绕过**：统一按归一化域名处理，减少 `www` / 子域切换绕过
- **强制模式**：开启后禁用“继续摸鱼”，冷静期内也不能直接跳走
- **拦截计数**：显示今日次数和累计次数，直面自己的摸鱼频率
- **反馈与激励**：显示连续专注天数、轻成就文案、本周最易分心站点
- **专注周报**：查看最近 7 天最容易分心的时段、站点和继续摸鱼原因
- **原因记录**：记录“逃避任务 / 无聊 / 习惯性打开”等继续摸鱼原因
- **随机语录**：每次拦截显示一言语录，激励或警醒
- **分组文案系统**：按当前状态动态切换温和提醒、直接制动、目标驱动、轻松吐槽
- **主题切换**：支持明亮/暗黑模式，可跟随系统或手动设置
- **网页限时使用**：为黑名单站点设置默认每日可访问分钟数，也可给单个网站自定义时长
- **选择时间段生效**：可仅在指定时间启用拦截和配额策略，支持 `21:00 - 00:00` 跨午夜范围
- **每日配额**：支持每日可访问分钟数/次数，额度耗尽后自动进入拦截页
- **本周趋势**：查看近 7 天拦截走势与高峰时段
- **站点排行**：统计被拦截最多的网站排名
- **控制台式设置面板**：集中管理目标、规则、白名单、生效时间、配额、主题和强制模式
- **高级规则**：支持域名、路径通配和正则规则，白名单优先生效
- **配置导入/导出**：用 JSON 备份或迁移配置和统计数据
- **黑名单管理**：通过菜单随时添加、删除、编辑拦截规则
- **自定义目标**：可设置重定向到任意网站

## 安装

### 前置要求

请先安装以下任一用户脚本管理器：
- [Tampermonkey](https://www.tampermonkey.net/) (推荐)
- [Violentmonkey](https://violentmonkey.github.io/)
- [Greasemonkey](https://www.greasespot.net/)

### 安装脚本

**方式一：从 Greasy Fork 安装**

[![Install](https://img.shields.io/badge/Install-Greasy%20Fork-red)](https://greasyfork.org/scripts/563551)

**方式二：手动安装**

1. 点击 [site-redirector.user.js](./site-redirector.user.js)
2. 点击 "Raw" 按钮
3. 用户脚本管理器会自动弹出安装提示

## 使用

脚本安装后自动生效。访问被拦截的网站时：

1. 页面显示拦截提示和 30 秒倒计时
2. 倒计时会以数字和进度环同步显示
3. 页面会根据当前状态显示不同风格的动态文案
4. 侧栏显示今日/累计/近 7 天统计和当前判断
5. 冷静期内刷新页面不会重置倒计时
6. 默认模式下，冷静期内可点击「算了，回去干活」立即跳转
7. 倒计时结束后出现红蓝药丸选择：
   - 💼 **蓝色药丸**：回去干活，跳转到工作页面
   - 🎮 **红色药丸**：继续摸鱼，记录原因后 5 分钟内不再拦截
8. 强制模式下：
   - 冷静期内没有直接跳转按钮
   - 倒计时结束后不能选择继续摸鱼
9. 无痕模式下会显示提醒文案，提示用户脚本可能受浏览器设置影响

## 高级规则

设置面板中的拦截规则和白名单规则都支持以下格式：

```text
bilibili.com
youtube.com/shorts*
regex:^https://example\.com/(feed|recommend)
```

规则匹配顺序：

1. 先匹配白名单规则，命中后直接放行
2. 再匹配拦截规则，命中后进入冷静期
3. 域名规则会自动覆盖子域名，如 `bilibili.com` 会匹配 `www.bilibili.com`

## 配置备份

打开「⚙️ 设置面板」后：

- 点击「导出配置」会生成 JSON，包含目标、规则、生效时间、默认配额、单站点配额、主题、强制模式和统计
- 粘贴 JSON 后点击「导入配置」即可恢复
- 旧版本的 `blacklist` 数据会自动迁移为新的拦截规则

## 网页限时使用

打开「⚙️ 设置面板」里的「生效策略」：

- **选择时间段生效**：勾选后，拦截规则和配额计时仅在指定本地时间范围内启用；例如 `21:00 - 00:00` 表示晚上 9 点到次日零点
- **跨午夜时段**：开始时间晚于结束时间时自动跨天，例如 `22:00 - 07:00`
- **全天生效**：不勾选时间段，或将开始和结束设置为相同时间

- **默认每日可访问分钟数**：没有单独配置的黑名单站点使用这个值；`0` 表示不开放配额，访问时直接进入冷静期
- **单站点每日分钟数**：每行一个域名和分钟数，覆盖默认值
- **每日可访问次数**：仍是全局次数限制；`0` 表示不限制次数

单站点配置示例：

```text
bilibili.com 20
douyin.com:10
weibo.com,15
```

脚本只统计当前可见标签页的停留时间。额度耗尽时，不需要刷新页面，会自动切到拦截页。域名规则命中的子域名会归到对应规则上计时，例如 `m.bilibili.com` 命中 `bilibili.com` 时使用 `bilibili.com` 的配额。

## 文案系统

脚本内置 4 组动态文案，会根据当前状态自动选择：

- **温和提醒**：默认场景，语气更轻，适合低频触发
- **直接制动**：今日多次分心或开启强制模式时使用
- **目标驱动**：连续专注天数较高时，偏鼓励和执行导向
- **轻松吐槽**：中等频率触发时，用更轻松的方式打断惯性操作

当前文案风格会直接显示在拦截页上，便于观察效果。

## 反馈和激励

- **连续专注天数**：按“当天没有选择继续摸鱼”统计
- **轻成就文案**：根据今日拦截次数、连续专注天数、强制模式动态变化
- **周报统计**：汇总最近 7 天最容易分心的时段、站点和摸鱼原因
- **原因记录**：继续摸鱼前会记录原因，用于后续周报分析

## 反绕过机制

- **刷新不中断冷静期**：冷静期期间刷新页面不会重新从 30 秒开始
- **子域名统一处理**：降低通过切换 `www` 或不同子域绕过的概率
- **无痕模式提醒**：检测到无痕上下文时给出提示
- **强制模式**：更适合需要硬约束的工作场景

## 默认配置

- **默认黑名单**：bilibili.com, douyin.com, weibo.com, x.com
- **默认重定向目标**：https://claude.ai
- **冷静期时长**：30 秒
- **临时绕过时长**：5 分钟
- **默认文案风格**：根据拦截次数、连续专注天数和强制模式动态切换
- **默认生效时间**：全天生效；设置面板可启用指定时段
- **默认强制模式**：关闭
